# Pocket Bansuri 🎶

**Pocket Bansuri** is a premium Android application designed to help bansuri (Indian bamboo flute) practitioners perfect their pitches and practice Hindustani classical Ragas. The app features a real-time pitch tuner mapped to Indian music notation (Swaras) and an interactive Raga library.

---

## 🌟 Core Features

### 1. Landscape 7-Hole Flute Visualizer
*   **Realistic Bamboo Design**: Rendered using custom Canvas graphics with realistic wood-grain gradients, traditional thread bindings, and a blowing hole (embouchure).
*   **State-Driven Fingering Animations**: Smoothly transitions between finger configurations for each Swara (**Sa, Re, Ga, Ma, Pa, Dha, Ni, High Sa**). Supports open (○), fully closed (●), and half-closed (◐) states.

### 2. Practice Station (Double-Tab Layout)
*   **Tuner Tab**:
    *   **Live Pitch Detection**: Polls the microphone input to detect pitch frequency in Hz.
    *   **Deviation Meter**: A linear visual gauge indicating whether the played note is in tune (Green, $\pm3$ Hz), flat (Red), or sharp (Orange).
    *   **Reference Tones**: Single-click to select a target Swara. Long-press/toggle to hear a high-quality reference tone generated by the audio engine to train your ear.
*   **Riyaaz Tab**:
    *   **Raga Library**: Features classical Hindustani Ragas such as **Yaman**, **Bhupali**, and **Hansadhwani**.
    *   **Scale Details**: Discloses Ascent (Aaroh), Descent (Avroh), King Note (Vadi), Queen Note (Samvadi), and descriptions.
    *   **Interactive Fingering Helper**: Tap any note in the Raga's scale to immediately update the visualizer and see the correct fingering chart.

## 🛠️ Technical Stack

*   **UI Framework**: Kotlin & Jetpack Compose (Material Design 3)
*   **Native Engine Support**: CMake & Android NDK (C++17)
*   **Target Android API**: SDK 36 (Android 16 preview)
*   **Build Tool**: Gradle 8.9 (Kotlin DSL)

## 📂 Project Architecture & Key Files

The project is structured with a clean separation of Compose UI views and JNI native components:

*   [`MainActivity.kt`](file:///run/media/anonymous/Study/Projects/PocketBansuri/app/src/main/java/com/pocketbansuri/MainActivity.kt): Entry point of the application. Forces Landscape mode and requests runtime microphone (`RECORD_AUDIO`) permissions.
*   [`AudioEngine.kt`](file:///run/media/anonymous/Study/Projects/PocketBansuri/app/src/main/java/com/pocketbansuri/AudioEngine.kt): Singleton Kotlin interface loading `native-lib` and declaring JNI hooks.
*   [`native-lib.cpp`](file:///run/media/anonymous/Study/Projects/PocketBansuri/app/src/main/cpp/native-lib.cpp): Native implementation containing stub functions and pitch fluctuation code to simulate active mic detection.
*   [`Swara.kt`](file:///run/media/anonymous/Study/Projects/PocketBansuri/app/src/main/java/com/pocketbansuri/model/Swara.kt): Defines Swara frequencies (base scale: C-Natural), MIDI notes, and finger configurations.
*   [`BansuriVisualizer.kt`](file:///run/media/anonymous/Study/Projects/PocketBansuri/app/src/main/java/com/pocketbansuri/ui/components/BansuriVisualizer.kt): Performs smooth, custom Canvas drawings of the flute holes based on the active Swara.

## 🚀 Getting Started

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/MihirrajDixit/PocketBansuri.git
    cd PocketBansuri
    ```
2.  **Open in Android Studio**:
    *   Launch Android Studio (Ladybug or newer recommended).
    *   Select **Open An Existing Project** and navigate to the `PocketBansuri` folder.
    *   The IDE will automatically resolve dependencies and build a `local.properties` file with your local Android SDK/NDK path.
3.  **Run on Device**:
    *   Connect your Android device or start an emulator.
    *   Build and run the project (`Shift + F10` or click **Run**).
    *   Accept the microphone permission prompt to enable real-time tuner updates.
